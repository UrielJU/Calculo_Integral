Métodos de Integración

Integración Directa

Definición

Aplicación inmediata de las fórmulas básicas de integración sin transformación previa.

∫ xⁿ dx = xⁿ⁺¹/(n+1) + C
∫ eˣ dx = eˣ + C
∫ 1/x dx = ln|x| + C

Ejemplos resueltos

Ejemplo 1:

∫ 3x² dx = 3·(x³/3) + C = x³ + C

Ejemplo 2:

∫ (2x + 5) dx = x² + 5x + C

Ejemplo 3 (trig. inversa):

∫ 1/√(1-x²) dx = arcsin(x) + C
Sustitución

Método

Se sustituye u = g(x) de modo que du = g'(x)dx, simplificando la integral.

∫ f(g(x))·g'(x) dx = ∫ f(u) du
  • Identificar la función interior u = g(x)
  • Calcular du = g'(x) dx
  • Sustituir y resolver
  • Volver a la variable original

Ejemplos resueltos

Ejemplo 1:

∫ 2x·(x²+1)⁵ dx → u = x²+1, du = 2x dx = ∫ u⁵ du = u⁶/6 + C = (x²+1)⁶/6 + C

Ejemplo 2:

∫ cos(3x) dx → u = 3x, du = 3dx = (1/3)∫ cos(u) du = sin(3x)/3 + C
Integración por Partes

Fórmula

∫ u dv = uv − ∫ v du

Se elige u y dv usando la regla LIATE:

  • Logarítmicas
  • Inversas trig.
  • Algebraicas
  • Trigonométricas
  • Exponenciales

Ejemplos resueltos

Ejemplo: ∫ x·eˣ dx

u = x, dv = eˣ dx du = dx, v = eˣ ∫ x·eˣ dx = x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C = eˣ(x − 1) + C
Fracciones Parciales

Método

Se descompone una fracción racional en fracciones más simples cuya integral se conoce.

P(x)/Q(x) = A/(x-r₁) + B/(x-r₂) + ...
  • Factorizar el denominador
  • Plantear la descomposición
  • Determinar constantes A, B, ...
  • Integrar cada fracción

Ejemplo resuelto

∫ 1/(x²-1) dx = ∫ 1/[(x-1)(x+1)] dx A/(x-1) + B/(x+1) → A=½, B=-½ = ½ ln|x-1| − ½ ln|x+1| + C = ½ ln|(x-1)/(x+1)| + C
Funciones Trigonométricas

Identidades útiles

sin²x = (1 − cos2x)/2 cos²x = (1 + cos2x)/2 sin²x + cos²x = 1

Funciones trigonométricas inversas

Las funciones inversas como arcsin y arctan aparecen en integrales de funciones racionales y radicales. Su evaluación depende de dominios concretos y ofrece expresiones cerradas para anti-derivadas.

∫ 1/√(1−x²) dx = arcsin(x) + C ∫ 1/(1+x²) dx = arctan(x) + C ∫ 1/(x√(x²−1)) dx = arcsec|x| + C

Ejemplos resueltos

∫ 1/√(1−x²) dx

= arcsin(x) + C

∫ 1/(4+x²) dx

= (1/2)·arctan(x/2) + C

∫ 1/√(9−x²) dx

= arcsin(x/3) + C

Dominio importante:

arcsin(x): x ∈ [−1,1], arctan(x): x ∈ ℝ
Cambio de Variable

Sustitución trigonométrica

Útil cuando aparecen expresiones del tipo √(a²−x²), √(a²+x²) o √(x²−a²).

√(a²−x²) → x = a·sin(θ) √(a²+x²) → x = a·tan(θ) √(x²−a²) → x = a·sec(θ)

Ejemplo

∫ √(1−x²) dx

x = sin(θ), dx = cos(θ)dθ √(1−x²) = cos(θ) = ∫ cos²(θ) dθ = θ/2 + sin(2θ)/4 + C = (arcsin(x))/2 + (x√(1−x²))/2 + C
